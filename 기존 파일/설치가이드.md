# TRPG 플랫폼 설치 가이드

구글 스프레드시트를 캐릭터/세션 DB로 쓰고, 그 위에 Apps Script로 만든 전용 웹앱(주사위 굴리기, 캐릭터 시트, 세션 로그, GM 도구)을 올리는 방식입니다. 이미 아래 스프레드시트가 계정 드라이브에 생성되어 있습니다.

- 스프레드시트: **TRPG 플랫폼 - 캐릭터&세션 DB**
- 링크: https://docs.google.com/spreadsheets/d/1WJQVL4I38ivCE5zjNCNCpQ2QcROeUuKMkkpFLMoKB_o/edit

탭 구성: 캐릭터 / 주사위기록 / 세션로그 / NPC_몬스터 / 게임상태 / 사용안내

## 1. Apps Script 프로젝트 열기

1. 위 링크로 스프레드시트를 엽니다.
2. 상단 메뉴 **확장 프로그램(Extensions) > Apps Script**를 클릭합니다. (반드시 이 스프레드시트 안에서 열어야 합니다 — 코드가 "현재 열려있는 스프레드시트"를 자동으로 데이터베이스로 사용하도록 짜여 있습니다.)
3. 처음 열리면 `Code.gs`라는 빈 파일이 하나 있을 거예요.

## 2. 백엔드 코드 붙여넣기

1. `Code.gs` 파일 안의 내용을 전부 지웁니다.
2. 전달드린 `Code.gs` 파일의 내용을 그대로 복사해서 붙여넣습니다.
3. 저장(Ctrl+S / Cmd+S).

## 3. 화면(프론트엔드) 파일 추가하기

1. 왼쪽 파일 목록에서 **+ 버튼 > HTML** 을 클릭합니다.
2. 파일 이름을 정확히 **index** 로 입력합니다 (`.html`은 자동으로 붙습니다). 이름이 다르면 작동하지 않아요.
3. 생성된 `index.html` 안의 기본 내용을 전부 지우고, 전달드린 `index.html` 파일의 내용을 그대로 붙여넣습니다.
4. 저장합니다.

## 4. 웹앱으로 배포하기

1. 오른쪽 위 **배포(Deploy) > 새 배포(New deployment)** 클릭.
2. 톱니바퀴(유형 선택) 클릭 후 **웹앱(Web app)** 선택.
3. 설정:
   - **실행 계정(Execute as)**: 나(Me)
   - **액세스 권한이 있는 사용자(Who has access)**: 파티원들과 링크로 공유할 거라면 **"링크가 있는 모든 사용자(Anyone with the link)"** 선택. (개인 Gmail 계정은 "특정 사용자만" 옵션이 없습니다. 링크 자체를 파티원에게만 공유하면 사실상 비공개로 쓸 수 있어요.)
4. **배포** 클릭 → 처음에는 권한 승인 화면이 뜹니다. 본인 계정으로 **고급(Advanced) > (프로젝트명)으로 이동 > 허용**을 눌러 승인하세요. (Google이 "확인되지 않은 앱"이라고 경고하는 건 정상입니다 — 본인이 만든 스크립트라서 그렇습니다.)
5. 배포가 끝나면 **웹앱 URL**이 나옵니다. 이 URL을 북마크하고 파티원들에게 공유하세요. 이게 곧 여러분의 TRPG 플랫폼입니다.

## 5. 코드를 나중에 수정했을 때

URL을 그대로 유지하면서 업데이트하려면:
1. Apps Script 편집기에서 **배포 > 배포 관리(Manage deployments)**
2. 연필(편집) 아이콘 클릭
3. 버전(Version)을 **새 버전(New version)**으로 바꾸고 **배포**

새로 배포를 만들면 URL이 바뀌므로, 웬만하면 이 방법을 쓰세요.

## 사용 방법 요약 (Roll20 / Foundry VTT / D&D Beyond / Owlbear Rodeo의 UX를 참고해 재구성)

화면 구조는 캐릭터 시트 / 솔로 플레이 / 활동 / GM 도구, 총 4개 탭 + 어디서나 뜨는 주사위 버튼으로 되어 있습니다. 앞의 세 항목(캐릭터 시트·활동·GM 도구)은 파티 플레이용이고, "솔로 플레이" 탭은 혼자 진행하는 D&D 기반 원샷 모험 전용입니다 (자세한 내용은 아래 "솔로 플레이 모드" 항목 참고).

- **캐릭터 시트 탭**: 목록에서 캐릭터를 고르면 오른쪽에 이름·직업·레벨·HP가 항상 보이는 요약 바가 뜨고, 그 아래 "개요"(스탯 등 핵심 정보)와 "상세 정보"(스킬·소지품·배경) 두 개의 서브탭으로 나뉩니다 — D&D Beyond 캐릭터 시트처럼 자주 보는 정보는 스크롤 없이, 세부 정보는 탭 뒤에 숨겨서 필요할 때만 열어보는 구조입니다. 스탯은 이름-값 쌍을 자유롭게 추가/삭제할 수 있어 어떤 시스템이든 쓸 수 있고, HP는 +1/+5/-1/-5 버튼으로 빠르게 조정됩니다.
- **주사위 굴리기 (플로팅 버튼)**: 화면 우측 하단의 동그란 주사위 버튼은 어느 탭에 있든 항상 떠 있습니다. 눌러서 위로 펼쳐지는 패널에서 굴리고, 굴린 뒤 그대로 캐릭터 시트든 GM 도구든 하던 걸 계속 볼 수 있어요 (Roll20·Foundry의 "채팅/주사위 패널이 항상 켜져 있는" 방식과 Owlbear Rodeo의 "필요할 때만 여는 오버레이" 방식을 섞은 형태입니다). `1d20`, `2d6+3`, `4d6kh3`(가장 높은 3개 유지), `2d20kh1`(어드밴티지), `2d20kl1`(디스어드밴티지) 등을 지원하고, natural 20/1은 자동으로 크리티컬 배지가 뜹니다.
- **활동 탭**: 세션 로그(내레이션/대사/판정/기타)와 방금 굴린 주사위 결과가 한 개의 시간순 피드로 합쳐져서 보입니다 (Foundry·Roll20의 "채팅 하나에 모든 게 쌓이는" 방식). 위쪽 필터 칩으로 "판정만" "주사위만" 처럼 즉시 걸러볼 수 있고, 다른 탭에 있을 때 새 활동이 생기면 탭 옆에 작은 점으로 알려줍니다.
- **GM 도구 탭**: "GM 모드 켜기"를 누르면 현재씬/라운드/공지 편집, **전투 순서(이니셔티브) 트래커**, NPC·몬스터 관리(HP 트래커 포함)가 나타납니다. 전투 순서는 이름과 선제값을 입력해 추가하면 자동으로 높은 순서로 정렬되고, 현재 턴인 참가자는 파란 테두리로 강조됩니다. "다음 턴" 버튼을 누르면 순서대로 넘어가고, 마지막 사람 다음에 다시 처음으로 돌아갈 때 라운드 숫자가 자동으로 하나 올라갑니다 (Foundry VTT의 전투 트래커와 같은 방식). 이 탭 전체는 화면을 가리는 용도일 뿐 진짜 보안 장치는 아니니, 정말 플레이어에게 숨기고 싶은 정보는 GM 본인만 따로 웹앱을 열어서 보는 걸 권장합니다.

### 휴대폰/좁은 화면에서 쓸 때

가로 폭이 좁아지면(휴대폰 등) 자동으로 레이아웃이 바뀝니다. 상단 탭 대신 화면 하단에 캐릭터/활동/GM 3개 아이콘이 있는 네비게이션 바가 뜨고, 캐릭터 탭은 "목록"과 "상세/편집" 두 화면을 위쪽 토글 버튼으로 오가는 방식으로 바뀌어 좁은 화면에서도 스크롤이 길어지지 않습니다. 주사위 버튼은 하단 네비게이션 위쪽에 겹치지 않게 자리를 잡습니다.

## 솔로 플레이 모드 (1인 진행)

파티 없이 혼자서도 D&D 기반의 짧은 모험을 진행할 수 있는 전용 탭이 추가되었습니다.

- **캐릭터 생성 위저드**: "솔로 플레이" 탭의 "+ 새 모험가 만들기"를 누르면 발더스 게이트 3 스타일의 단계별 위저드가 열립니다. 종족 → 클래스 → 배경 → 능력치(포인트 바이, 총 27점) → 이름·외형 → 최종 확인 순서로 진행하며, 각 단계는 카드를 클릭해 선택하는 방식입니다. 완료하면 자동으로 HP·AC가 계산되어 모험가가 만들어지고, 곧바로 시나리오가 시작됩니다.
- **원샷 시나리오 "안개 낀 숲"**: 실종된 상단을 좇아 안개 낀 숲으로 들어가는 분기형 이야기입니다. 장면마다 선택지를 고르거나, 능력치 판정(주사위)으로 성공/실패가 갈리거나, 간이 전투(공격 굴림 → 명중 시 피해 굴림 → 상대 반격)를 치르게 됩니다. 선택과 판정 결과에 따라 "무사 귀환", "숲의 진실을 밝히다"(최고의 결말), "안개 속으로"(여운이 남는 결말), "쓰러지다"(패배) 등 서로 다른 결말로 이어집니다.
- **진행 상황 자동 저장**: 장면을 이동하거나 전투 한 라운드가 끝날 때마다 진행 상황이 자동 저장됩니다. 중간에 다른 탭으로 이동했다가 돌아와도, 목록에서 같은 캐릭터의 "모험 시작"을 다시 누르면 이어했던 장면부터 계속됩니다. "다시 도전하기"를 누르면 HP를 모두 회복하고 처음부터 새로 시작합니다.
- **시트 자동 생성**: 솔로 캐릭터는 `솔로_캐릭터`라는 별도 탭에 저장되는데, 스프레드시트에 이 탭이 아직 없어도 처음 캐릭터를 만드는 순간 자동으로 만들어집니다. 직접 탭을 추가할 필요가 없습니다. 진행 상황(현재 장면, 선택 기록 등)은 기존 `게임상태` 탭에 `솔로진행_<캐릭터ID>` 키로 저장되어 별도 시트가 필요 없습니다.
- **GM 진행 방식에 대한 참고**: 이번 버전의 "GM"은 실시간으로 응답을 만들어내는 AI가 아니라, 미리 작성해 둔 분기형 시나리오입니다. 매 턴 AI를 호출하는 방식이 아니기 때문에 별도의 API 비용 없이 지금 배포한 그대로 바로 쓸 수 있습니다. 시나리오는 현재 "안개 낀 숲" 한 편이 들어 있으며, 이후 새로운 원샷 시나리오를 요청하시면 같은 방식으로 추가해 드릴 수 있습니다.

## 최근 수정 사항 (재배포 필요)

아래 내용이 반영된 `Code.gs` / `index.html`을 다시 붙여넣고, "4. 코드를 나중에 수정했을 때" 안내대로 **배포 관리 > 새 버전**으로 재배포해야 실제로 적용됩니다.

- **주사위 굴리기가 활동 피드에 바로 안 뜨던 문제**를 고쳤습니다. 솔로 플레이 중 판정/전투에서 굴린 주사위도 이제 파티 모드처럼 굴리는 즉시 활동 피드용 데이터를 다시 불러오고, 활동 탭이 아니면 안 읽음 표시(점)가 바로 뜹니다. (예전에는 최대 6초 뒤 자동 새로고침 때까지 기다려야 보였습니다.)
- **스프레드시트를 직접 수정했을 때 캐릭터 목록이 통째로 안 보이던 문제**를 예방하는 방어 코드를 추가했습니다. 특정 한 행의 값이 이상해도(예: 이름 칸에 숫자만 입력됨) 그 행 때문에 목록 전체가 사라지지 않고, 나머지 캐릭터는 정상적으로 보입니다. 문제가 있는 행은 브라우저 콘솔(F12)에 어떤 캐릭터인지 로그로 남습니다. 이 문제가 다시 발생하면 F12 콘솔의 오류 메시지와 `솔로_캐릭터` 시트 1행(헤더)이 `ID, 캐릭터명, 종족, 클래스, 배경, 능력치(JSON), 현재HP, 최대HP, 스킬/특기, 소지품, 외형, 골드, 최종수정`과 정확히 일치하는지 확인해주시면 원인을 더 좁힐 수 있습니다.
- **체감 무게 개선(1차)**: 브라우저 탭이 백그라운드에 있을 때(다른 탭/창을 보고 있을 때)는 자동 새로고침을 쉬도록 해서 불필요한 서버 호출을 줄였습니다. 탭으로 돌아오면 즉시 한 번 새로고침해 최신 상태를 바로 보여줍니다. 화면 구조나 기능은 그대로이며, 더 큰 구조 변경(정적 프론트+API 분리, 완전 재작성 등)은 아직 진행하지 않았습니다 — 필요하면 다음 단계로 진행할 수 있습니다.

## 알아두면 좋은 점

- 여러 명이 같은 URL을 동시에 열어도 됩니다. 각자의 조작은 스프레드시트에 바로 반영되고, 화면은 몇 초 간격으로 자동 새로고침되어 서로의 변경사항이 보입니다. 다만 완전한 실시간(웹소켓 수준)은 아니라서 아주 미세한 타이밍 충돌(같은 순간 같은 값 동시 수정)은 이론상 가능합니다 — 소규모 고정 파티 용도로는 문제 없는 수준입니다.
- 스프레드시트를 직접 열어서 표를 수정해도 반영됩니다 (표와 웹앱이 같은 데이터를 보고 있어요). 전투 순서는 "게임상태" 탭에 `전투순서`/`현재턴` 키로 JSON 형태로 저장됩니다 — 시트 구조를 새로 만들 필요는 없습니다.
- `스탯(JSON)` 칸은 형식이 깨지면 빈 값으로 처리되니, 웹앱의 "스탯 추가" 버튼으로 편집하는 걸 권장합니다.
